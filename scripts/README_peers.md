# 해외 반도체 소부장 기업 수집(파일럿)

배포할 때마다 `build_peers.py`가 `peers_master.csv`의 기업을 수집해 `site/data/peers.js`를 만듭니다. 화면은 `site/compare.html`(해외 비교)입니다.

## 기업 추가·삭제

`peers_master.csv`에서 줄만 추가하거나 지우면 됩니다. 각 열은 다음과 같습니다.

| 열 | 뜻 | 예 |
|---|---|---|
| id | 내부 고유 키(영문 소문자) | `tel` |
| name | 표시 이름 | `Tokyo Electron` |
| ctry | 국가 코드 | `US`·`JP`·`NL`·`DE`·`FR`·`IL`·`CN`·`KR` |
| listed | 상장 여부 | `Y` |
| ticker | 야후 파이낸스 티커(주가·재무) | `8035.T` |
| source | 재무 수집 경로 | `sec`(미국 SEC) · `yf`(야후) · `dart`(한국 DART 연결) |
| code | 경로별 코드 | SEC는 티커, DART는 고유번호 |
| cur | 재무 통화(야후가 알려 주면 그 값을 씁니다) | `USD`·`JPY`·`EUR`·`CNY` |
| cat | 소부장 분류 | 장비 · 부품 · 소재 · 후공정·테스트 · 팹리스·설계 · 제조(IDM·메모리) |
| dom_kind | 국내 소부장과 비교할 업종(없으면 빈칸) | 장비 · 부품 · 소재 |
| seg1 / seg2 | 주력 / 보조 분야 | `증착·식각` / `세정` |

환율은 ECB 기준이라 ECB가 고시하지 않는 통화(예: 대만 달러)의 기업은 원화로 환산되지 않습니다.

## 수집 규칙

- 원 통화 값(백만 단위)과 원화 환산값(억 원)을 따로 저장합니다. 손익은 회계연도 평균 환율, 재무상태표는 결산일 환율로 환산하고, 환율과 출처도 함께 남깁니다.
- 값이 없으면 0이 아니라 빈 값으로 둡니다. 기업마다 수집 상태를 남깁니다.
  - 확보: 최근 연도 매출·영업이익·순이익이 모두 있음
  - 일부 확보: 이 셋 중 일부만 있음
  - 미확보, 파싱 실패, 접속 실패: 수집하지 못함(이유를 함께 남김)
- 미국 SEC는 GitHub Actions(클라우드)에서 403으로 막혀 야후 파이낸스로 대체합니다. 사내 서버처럼 SEC 접속이 되는 곳에서 실행하면 공식 경로(SEC EDGAR XBRL)를 자동으로 씁니다. 연락처는 `SEC_USER_AGENT` 환경변수로 바꿀 수 있습니다.

## 다음 단계(미구현)

- 일본: 금융청 EDINET API. 인증키가 필요하며, 키를 `EDINET_API_KEY` secret으로 넣으면 연동할 수 있습니다.
- 유럽: ESEF 공시(filings.xbrl.org). 영국은 Companies House API(인증 필요)입니다.
- 중국: CNINFO와 거래소 공시입니다.
- 사업부문별(반도체) 매출 비중은 각 사 연차보고서에서 직접 확인해야 해서, 아직 수집하지 않습니다.

## 시험 실행

GitHub Actions의 `peers-collect`(수동 실행)를 씁니다. `peers_only`에 국가 코드나 id를 쉼표로 넣으면 일부만 수집합니다. 결과는 로그의 `[peers-json]` 줄과 artifact로 확인합니다.
