# 현재 상황 브리핑 (ChatGPT 전달용)

## 목표
국내 상장 **반도체 소재·부품·장비(소부장)** 기업의 빠짐없는 모집단을 확정하고, 코스피·코스닥·코넥스 전체 시장 대비 비중(종목 수·시가총액)을 구한다. 누락 방지가 최우선이며, 최종 포함 여부는 사용자가 판단한다.

## 방식
1. DART OpenAPI로 전체 상장사 4,009곳의 업종코드(KSIC)를 조회해 후보를 넓게 뽑는다(팹리스 등 소부장이 아닐 수 있는 곳도 포함).
2. 최종은 사업보고서 "사업의 내용"으로 실제 소부장 사업 여부와 분류 근거를 확인한다.
3. 시가총액은 네이버증권 공개 JSON(stock.naver.com)으로 읽는다.
4. 구현: GitHub Actions 수동 실행 워크플로(`semi-count`, `semi-verify`), 저장소 `captaincatb-web/Sangsaengnews`.

## 사용자 지정 규칙
- 분류: 원익IPS 장비, LG이노텍 부품, 삼성전기 부품, LG화학·고려아연 소재, 레인보우로보틱스 부품, 한화비전 장비(포함)
- 제외: 삼성SDS, 삼성물산, 삼성E&A, LS일렉트릭, HD현대일렉트릭, 효성중공업, 에스원, 에스넷시스템, 폴라리스오피스, 젬백스앤카엘, 세방전지

## 지금까지의 결과
- 전체 상장사 4,009곳 조회 완료(실패 0). 시장별: 코스피 829, 코스닥 1,826, 코넥스 107, 기타 1,247(ETF 등).
- **확정 소부장 139곳**: 장비 56(코스피 8·코스닥 48), 부품 46(코스피 13·코스닥 32·코넥스 1), 소재 37(코스피 12·코스닥 25). (협력사 명단 147곳 중 144곳 DART 매칭, 이전 123곳에서 16곳 증가. IT·서비스 4곳, 미분류 1곳은 제외)
- **시장 대비 비중(네이버 시총 기준)**: 코스피 33곳 3.98% / 시총 230.2조 / 4.96%, 코스닥 105곳 5.75% / 시총 103.3조 / 25.65%. 코스피 부품 시총(160조)은 삼성SDI·두산 등 대형주 때문에 커 보이며 소부장 해당 여부 확인 필요. 코넥스는 네이버에 없어 시총 비교 불가. 시장 전체 시총은 네이버 4,637.9조(코스피) vs 사용자 표 4,578.45조로 기준일 차이.
- **추가 판정 대상 1,114곳**(후보 CSV): A등급(반도체 직접 업종) 신규 89, B등급(장비·소재·부품 계열 업종) 신규 770(화학·화장품·철강·의료기기가 많아 선별 필요), C등급(이름 규칙) 신규 100, 기존 비소부장 5, 지정 제외 11.
- 사용자가 준 협력사 90곳(7개 분과: 국내·해외 FAB 장비, FAB 부품, FAB 원자재, P&T 장비부품, P&T 원자재, 인프라) 대조: 28곳은 확정 목록에 있고 62곳은 상장 여부 판정 전. 해외 장비사 11곳은 외국계 한국법인(비상장 추정). 브이엠·유니테스트는 A등급 후보에서 발견.

## 진행 중
- `semi-verify` 실행 중: A·B 신규 후보 + 협력사 90곳의 최신 사업보고서 "사업의 내용"을 읽고 반도체 언급 수·키워드(장비/부품/소재/팹리스)로 제안을 붙인다. 결과는 `semi_verify.csv`.
