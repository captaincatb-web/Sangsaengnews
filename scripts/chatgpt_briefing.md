# 현재 상황 브리핑 (ChatGPT 전달용, 2026-11-01 기준)

## 목표
국내 상장 **반도체 소재·부품·장비(소부장)** 기업의 누락 없는 모집단을 확정하고, 코스피·코스닥·코넥스 전체 시장 대비 비중(종목 수·시가총액)을 구한다. 최종 포함 여부는 사용자가 판단한다. 팹리스·설계 업체는 제외한다.

## 사용 데이터·방식
- DART OpenAPI: 전체 상장사 4,009곳(코스피 829·코스닥 1,826·코넥스 107·기타 1,247) 업종코드 조회 완료(실패 0), 후보 1,114곳 도출
- 사업보고서 "사업의 내용" 키워드 점검: 954곳(`scripts/semi_verify_rows.csv`)
- 네이버증권 공개 JSON: 시가총액(코스피 4,637.9조·코스닥 402.6조, 보통주 기준)
- 사용자 첨부 "반도체 공급망 202개사 통합 마스터"(ChatGPT 작성 추정)와 네이버 "반도체와반도체장비" 업종 167종목을 대조해 반영
- 코드·데이터 저장소: `captaincatb-web/Sangsaengnews` (GitHub Actions 수동 실행 `semi-count`, `semi-verify`)
