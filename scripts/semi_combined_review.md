## 6. 검증 한계와 다음 작업

1. 이번 통합은 97개 + 71개 원본을 종목코드로 결합하고 중복 5개를 제거한 작업이다. 163개 모두의 최신 사업보고서 검증을 완료했다는 뜻은 아니다.
2. 원자재·부품 71개는 사용자가 제공한 네이버 테마 JSON의 종목 설명을 1차 분류 근거로 사용했다. 네이버 테마 편입만으로 최종 포함을 확정하지 않는다.
3. 장비 97개는 기존 검토 CSV의 분류·근거를 유지했다. 근거 URL이 없는 행은 추가 공시 검증 대상이다.
4. 다음 단계는 조건부 38개 우선 검증, 유통·모듈·소자·중고장비의 통계 경계 확정, 원자재·부품 후보의 사업보고서상 반도체 매출 검증이다.
5. 최종 모집단 확정 전에는 기존 사이트의 123개 시총 데이터·134개 분석 모집단·158개 명단을 덮어쓰지 않는다.
