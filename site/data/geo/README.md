# 지역별 소부장 산업지도 v1 (프로토타입)

- 위치: `site/dashboard.html` → 산업·업종 분석의 독립 지도 카드
- 경계: `site/data/geo/korea-sido.svg` (17개 시·도, 단순화 SVG)
- 원본: [StatGarten/maps](https://github.com/statgarten/maps), `svg/simple/전국_시도_경계.svg`
- 원본 명시 시점: SGIS 2020년 경계. 최신 2026년 행정경계라고 주장하지 않음.
- 원본 저장소 코드 라이선스: MIT (Copyright (c) 2022 StatGarten). 경계의 원자료는 통계청 SGIS이고, 화면에 출처를 표시함.
- 데이터: 기존 DART 본사 주소(`r.ad`)와 같은 시점의 대시보드 필터 결과(`SB.panel` 이후)만 사용.
- 본사 주소 미확인 기업은 별도 집계. 공장·사업장 위치나 소재지 생산액으로 해석 금지.
- 지역 표시 이름: 원본 지도에 남은 '강원도','전라북도'는 UI에서 '강원특별자치도','전북특별자치도'로 표기.
- 지도 내 시·도 선택은 현 단계에서 **지역 분석 카드에만 적용**되며, 상단의 6개 권역 필터와 독립.
- URL 필터 및 기존 기업 포트폴리오·신호 분석 코드를 변경하지 않음.

## 파일 및 검증

- `site/dashboard-map.js`: SVG 로드/집계/호버/선택/기업 목록/키보드 조작
- `site/dashboard-map.css`: PC·모바일·다크 모드 대응
- `site/dashboard.js`: 렌더링 시 기존 필터 결과만 지도에 전달하는 한 줄 추가
- `site/dashboard.html`: 산업 분석 카드, CSS 및 JS 링크 추가

통합 시험 시 확인할 사항:
1. 지도 17개 경계 표시, 강원/전북 변경명 정규화
2. 전체 필터 변경 후 지도 집계 및 주소 미확인 숫자 변화
3. 지역 선택 후 기업 목록과 `#company` 상세 화면 연결
4. 매출 성장률은 동일 기업의 당기/전기 합산 매출 비교. 샘플이 없으면 미집계 표시
5. 주소 미확인 기업 강제 분류하지 않음
6. 휴대폰(360px), PC(1280px) 및 다크모드에서 시각 확인
7. 기존 CSV, 보고서, 산업 그래프, URL 필터 및 데이터 수집 파이프라인 회귀 시험

후속 단계: 검증된 2026 행정경계로 교체, 정확도 높은 시군구/사업장 지점 매핑, 17개 시도 전역 필터 통합 등.
