내부 정보 암호화

기업규모·거래 관계·반도체 매출 비중을 비밀번호로 암호화한 파일을 만듭니다. 모든 처리는 이 브라우저 안에서만 이루어지고, 입력한 내용과 비밀번호는 어디로도 전송되지 않습니다.

1. 내부 정보 붙여 넣기

엑셀에서 아래 열 순서대로 복사해 붙여 넣으세요(탭 또는 쉼표 구분, 첫 줄은 제목). 업체코드는 DART 고유번호 8자리이며, 없으면 업체명으로 찾습니다.

업체코드 업체명 기업규모 거래관계 반도체비중 00365457 제이티 중견 당사 거래 85 코세스 중소 비거래 60

2. 비밀번호 정하기

12자 이상으로 정하고, 볼 권한이 있는 분께만 따로 전달하세요. 비밀번호를 잃으면 파일을 다시 만들어야 합니다.

3. 파일 올리기

  1. 파일 받기를 누르면 internal.enc.js가 저장됩니다.
  2. GitHub 저장소의 site/data/ 폴더에 같은 이름으로 올리거나, 이 파일을 Claude에게 전달하세요. 암호문이라 전달해도 내용은 보이지 않습니다.
  3. 배포 후 대시보드의 내부 정보 보기에서 비밀번호를 넣으면 표시됩니다.
