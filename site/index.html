    요청한 회사명이 GitHub 이슈로 저장됩니다. 새 창에서 Create(이슈 등록)를 눌러 주세요. 저장만 되고 목록에는 바로 들어가지 않으며, 담당자가 확인한 뒤 반영합니다.

    이용 안내

    자료 기준
    재무는 개별(별도) 재무제표 기준입니다. 상장사는 사업보고서, 비상장사는 감사보고서에서 읽고, 최근 분기 실적을 함께 보여 줍니다. 주가와 시가총액은 전 거래일 종가입니다.
    갱신
    매일 오전 7시 30분에 DART와 주가 자료를 다시 받아 자동으로 고칩니다.
    Word로 옮기기
    표 위의 표 복사, 기업 프로필의 Word로 복사를 누른 뒤 Word에 붙여 넣으면 표와 서식이 그대로 들어갑니다.
    추가 요청
    그룹 탭 옆 추가 요청에 회사명을 넣고 GitHub에서 이슈를 등록하면 요청이 저장되고, 담당자가 확인한 뒤 목록에 넣습니다.
