# 데이터 사전

## direct_sme_candidates_20261101.csv
- 110개 직접 소부장 후보 레코드.
- company_ko: 기업명
- category: 장비/부품/소재
- entity_status: 국내 법인 성격
- market: KRX 시장
- ticker: 6자리 종목코드 문자열
- classification_status: 원본 마스터의 판정 결과
- 후보 목록이며 최종 확정 모집단이 아니다.
- 시가총액 열은 이 CSV에 없다. 시가총액은 별도 시장 데이터셋(KRX)으로 관리하고, 분석 단계에서 `ticker`(6자리 종목코드)와 기준일로 결합한다. 시가총액 데이터에는 원본 단위, 변환 단위, 기준일, 증권유형, 출처를 함께 기록한다.
- OCI(`456040`)와 OCI홀딩스(`010060`)는 서로 다른 상장법인이다(2026-11-01 사용자 확정). 후보 CSV의 OCI는 `456040`이다. 종목코드 정정은 반도체 소부장 해당 여부와 별개다.
