# 네이버증권 수집 데이터 안내서

이 문서는 현재 저장소의 `scripts/count_listed_semi.py`가 네이버증권에서 가져오는 데이터가 무엇인지, 각 항목을 어떻게 읽고 분석에 사용하는지 설명한다.

> 주의: 네이버 웹 API는 공개된 정식 데이터 계약서가 확인된 API가 아니다. 아래 설명은 현재 저장소 코드와 확인된 요청 방식 기준이다. 응답 필드·페이지 규칙은 바뀔 수 있으므로 실행 시 실제 응답을 검증하고, 변경되면 이 문서와 테스트를 함께 수정한다.

## 1. 네이버에서 가져오는 데이터는 크게 2종류

| 구분 | 가져오는 내용 | 분석 목적 | 주의 |
|---|---|---|---|
| 시장별 종목 목록 | KOSPI·KOSDAQ 종목코드, 종목명, 증권 유형, 시가총액 | 종목별 시총 매칭 및 시장별 시총 합계 | KONEX 전체 목록을 이 함수가 수집하지 않음 |
| 반도체 업종 구성 종목 | 네이버 업종번호 278에 포함된 종목코드 | 반도체 업종 관련 종목 후보 확인 | 소부장 확정 목록이 아님 |

## 2. 시장별 종목 목록 API

요청 주소:
`https://stock.naver.com/api/domestic/market/stock/default`

현재 코드가 보내는 주요 파라미터:

| 파라미터 | 예시 | 쉬운 설명 |
|---|---|---|
| `tradeType` | `KRX` | 한국거래소 기준 데이터 요청 |
| `marketType` | `KOSPI` 또는 `KOSDAQ` | 어느 시장의 종목을 가져올지 지정 |
| `orderType` | `marketSum` | 시가총액 기준 정렬 |
| `startIdx` | `0`, `1` 등 | 목록을 나눠 읽기 위한 페이지/시작 위치 값. 정확한 동작은 응답 비교로 판별 |
| `pageSize` | 현재 코드 기본값 `10` | 한 번에 요청하는 목록 크기 |

### 응답에서 현재 코드가 사용하는 필드

| 원본 필드 | 의미 | 저장/활용 방식 |
|---|---|---|
| `itemcode` | 종목코드 | KRX 종목 마스터와 연결하는 핵심 키. 문자열로 보존 |
| `itemname` | 종목명 | 사람이 확인하는 이름. 종목코드보다 우선하는 식별키로 사용하지 않음 |
| `type` | 네이버 응답의 증권 유형 코드 | 현재 코드는 `ST` 또는 필드 누락 행을 통과시키고, 그 외 유형은 제외 |
| `marketSum` | 시가총액 원본 값 | 숫자 변환 후 코드에서 1억으로 나눠 억원 단위로 변환하고 반올림 |

**시가총액 단위 변환**

현재 코드의 처리식은 다음과 같다.

`시가총액(억원) = round(marketSum 원본값 ÷ 100,000,000)`

- 원본값이 숫자 또는 숫자 문자열일 수 있어 쉼표를 제거한 뒤 숫자로 변환한다.
- 현재 코드는 값이 비어 있거나 숫자 변환에 실패하면 0으로 처리하고, 0보다 큰 값만 결과에 넣는다.
- 분석용 데이터셋에서는 결측값과 실제 0을 구분하는 편이 안전하다. 후속 개선 시 원본값, 변환값, 변환 실패 여부를 별도 보존한다.
- 화면이나 보고서에서는 반드시 단위를 `억원` 또는 `조원`으로 표시한다. 원본 숫자를 단위 없이 노출하지 않는다.

### 현재 코드의 수집·필터링 규칙

1. KOSPI와 KOSDAQ을 각각 요청한다.
2. 시가총액 정렬 목록을 페이지 단위로 반복 요청한다.
3. `itemcode` 기준으로 중복 행을 제거한다.
4. `type`이 `ST`가 아닌 행은 제외한다. 단, `type` 필드가 없는 행은 현재 코드상 통과한다.
5. 시가총액이 정상적으로 숫자 변환되고 0보다 큰 행만 결과에 저장한다.
6. 두 시장 모두 수집에 성공하고 결과가 존재하면 JSON API 결과를 사용한다. 그렇지 않으면 PC 금융 페이지 표 파싱을 대체 경로로 사용한다.

### 페이지 처리에서 주의할 점

네이버 응답의 `startIdx`가 페이지 번호인지, 건너뛸 행 수인지 요청 결과만 보고 단정하지 않는다. 현재 코드는 첫 번째와 두 번째 요청의 종목코드 겹침 여부를 비교해 다음 세 방식 중 하나로 판별한다.

- `page1`: 0과 1이 같은 목록이면 다음 값을 2, 3, …으로 요청
- `offset`: 일부 종목이 겹치면 pageSize 단위로 이동
- `page0`: 종목이 겹치지 않으면 0부터 시작하는 페이지 번호로 간주

이 로직은 네이버 API의 공식 보장이 아니라 응답 패턴에 대응하기 위한 휴리스틱이다. 페이지별 종목코드 중복, 누락, 마지막 페이지 도달 여부를 로그와 테스트로 확인한다.

## 3. 네이버 반도체 업종 구성 종목

현재 코드 요청 경로:
`/api/domestic/market/upjong/278/stocklist`

현재 요청 시장:
- `marketType=KOSPI`
- `marketType=KOSDAQ`

현재 코드에서 사용하는 업종번호 278의 표시명은 **반도체와 반도체장비**다.

이 응답은 구성 종목의 `itemcode` 또는 `itemCode`를 추출해 업종 구성 종목 코드 목록으로 사용한다.

**중요한 해석 제한**
- 네이버 업종 278에 포함됐다는 사실만으로 해당 기업을 소재·부품·장비 기업으로 확정하지 않는다.
- 팹리스, 종합반도체기업, 후공정 업체, 장비·부품·소재 업체가 함께 포함될 수 있다.
- 업종 구성 종목은 후보 발굴·교차 검증에 활용하고, 최종 소부장 판정은 기업별 제품·사업 내용과 프로젝트 분류 기준으로 수행한다.
- 이 요청도 현재 코드상 KOSPI·KOSDAQ만 조회하므로 KONEX 전체 모집단 수집을 대체하지 않는다.

## 4. 분석에서 이렇게 사용한다

| 질문 | 사용할 데이터 | 계산/판정 |
|---|---|---|
| 이 종목의 시가총액은? | `itemcode`, `marketSum` | 종목코드로 KRX 마스터와 연결 후 억원/조원 표시 |
| KOSPI 소부장 시총은? | 소부장 확정 목록 + KOSPI 시총 목록 | 동일 기준일의 매칭 종목 시총 합계 |
| KOSDAQ 소부장 시총 비중은? | 소부장 시총 합계 + KRX 시장 전체 시총 | 분자·분모 기준일과 단위 일치 후 계산 |
| 반도체 관련 후보는? | 업종 278 구성 종목 | 후보 목록으로만 사용, 기업별 직접 판정 필요 |
| KONEX 소부장 규모는? | KRX 종목 마스터 및 별도 시총 원천 | 네이버 시장 목록 수집 결과만으로 완결하지 않음 |

### 시가총액 비중 산식

`시장 내 소부장 시총 비중(%) = 소부장 상장기업 시가총액 합계 ÷ 해당 시장 전체 시가총액 × 100`

주의: 분자와 분모가 같은 기준일이어야 한다. 네이버 시가총액은 상장기업 전체 가치이며, 다각화 기업의 반도체 사업부 가치가 아니다.

## 5. 데이터 화면 권장 표기

원본 API 키를 그대로 화면에 나열하지 말고 다음처럼 한글 항목명으로 보여준다.

| 화면 표시명 | 내부 필드 | 예시 형식 |
|---|---|---|
| 종목코드 | `itemcode` | `005930` |
| 종목명 | `itemname` | 삼성전자 |
| 시장 | 요청의 `marketType` | KOSPI |
| 증권유형 | `type` | ST / 미제공 |
| 시가총액 | `marketSum` 변환값 | 000,000 억원 |
| 수집 출처 | 고정 메타데이터 | 네이버증권 API |
| 수집 기준일시 | 수집 실행 시각 | ISO 8601 |
| 수집 상태 | 수집 검증 결과 | 정상 / 일부 누락 / 대체 경로 사용 |

시장 구분은 요청 파라미터로부터 기록한다. API 응답 행에 시장 필드가 있다고 가정하지 않는다.

## 6. 품질 검증 체크리스트

- [ ] KOSPI·KOSDAQ 수집 건수와 KRX 종목 마스터의 종목코드 집합 비교
- [ ] 종목코드 누락·중복·비정상 형식 확인
- [ ] 페이지 경계에서 중복 또는 누락 발생 여부 확인
- [ ] `type` 누락 행의 실제 증권 유형을 KRX 종목 마스터와 대조
- [ ] 시가총액 숫자 변환 실패와 실제 0을 구분
- [ ] 네이버 시총 합계와 KRX 시장 전체 시총의 기준일·단위 일치 확인
- [ ] KONEX는 별도 원천으로 보완
- [ ] API 실패 시 PC HTML 대체 경로 사용 여부를 결과에 표시
- [ ] 업종 278 포함 여부를 소부장 확정 판정으로 오인하지 않도록 화면에 안내

## 7. 한 줄 요약

**네이버에서 가져오는 핵심은 종목코드별 시가총액과 반도체 업종 구성 종목 목록이다.** 종목코드는 KRX 마스터와 연결하고, 시가총액은 시장 규모 계산에 사용하며, 업종 278은 후보 발굴용으로만 사용한다. 기업이 실제 소부장인지 여부는 별도의 제품·사업 검증으로 결정한다.
